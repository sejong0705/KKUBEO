# KKUBEO

"꾸버" 꾸준히 버티다 라는 약어로   
꾸준한 성장을 돕는 습관 형성 앱입니다.   
사용자가 AI 와 상담을 통해 함께 목표를 세우고 달성할 수 있게 지원합니다.

## 구현환경
```
IDE : Android Studio (version - 2024.3)
Framework : Flutter SDK (version - 3.29.2)
DB 저장소 : Firebase
AI 연동 : OpenAI GPT API
테스트 : chrom & 안드로이드 에뮬레이터
프로젝트 관리 : Notion ( 칸트차트 및 기능 진행률 기록 )
```
